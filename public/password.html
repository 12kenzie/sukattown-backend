📝 How to use:
  1. Click "Generate Hash via API" button above
  2. Copy the generated hash
  3. Go to your Firebase Console
  4. Navigate to: users → [your-user-id] → password
  5. Replace sukattown_admin_grp1 with the copied hash
  6. Save and try logging in again!

🔧 Alternative: Use Backend API Directly

Add this temporary endpoint to your backend (server.js):

// Temporary password hashing endpoint app.post("/api/auth/hash-password", async (req, res) => { const { password } = req.body; if (!password) { return res.status(400).json({ success: false, message: "Password required" }); } try { const hash = await bcrypt.hash(password, 10); res.json({ success: true, hash }); } catch (error) { res.status(500).json({ success: false, message: "Hash failed" }); } });

Then redeploy and click the button above!
